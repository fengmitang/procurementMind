# 后端接口联调说明

更新时间：2026-07-30

## 1. 联调边界

采购后端提供采购业务、供应商、推荐、Agent 会话存储和通知 Outbox 接口。

- 外部 Agent 只通过 HTTP API 调用采购后端，不直接访问 MySQL 或 Redis。
- 采购后端不实现大模型调用、提示词、意图识别、回复生成或工具编排。
- 通知发送通过平台无关的 HTTP 网关完成，采购业务层不直接依赖飞书 SDK。

## 3. 身份签名

除健康检查外，业务接口都需要以下请求头：

- `X-Platform-Type`
- `X-Platform-User-Id`
- `X-Gateway-Timestamp`
- `X-Gateway-Nonce`
- `X-Gateway-Signature`

签名原文依次为 HTTP 方法、URL 路径、平台类型、平台用户标识、时间戳和随机数，
字段之间使用换行符连接。使用 `IDENTITY_GATEWAY_SECRET` 生成 HMAC-SHA256
十六进制摘要。

签名不包含查询字符串。默认只接受 300 秒内的签名；同一随机数在有效期内不能
重复使用。

## 4. 外部 Agent 接口

主要接口：

- `POST /api/v1/agent/conversations/active`
- `POST/GET /api/v1/agent/conversations/{conversation_id}/messages`
- `GET/PUT /api/v1/agent/conversations/{conversation_id}/state`
- `POST /api/v1/agent/conversations/{conversation_id}/snapshot`
- `POST /api/v1/agent/conversations/{conversation_id}/complete`

规则：

- MySQL 保存会话元数据、完整消息和关键状态快照。
- Redis Key 为 `agent:session:{conversation_id}`，默认 TTL 为 72 小时。
- Redis Key 丢失时，后端自动从 MySQL 快照恢复。
- `external_message_id` 在同一会话内用于消息幂等。
- 不保存或返回模型内部思维过程。

## 5. 采购查询接口

- `GET /api/v1/purchase-records`：按采购编号、设备、供应商、状态和日期查询。
- `GET /api/v1/requirements/{requirement_id}/timeline`：查询关键流程操作。
- `GET /api/v1/requirements/{requirement_id}`：查询采购详情。
- `GET /api/v1/suppliers`：查询供应商。
- `GET /api/v1/recommendations/*`：查询历史参考数据。

后端根据当前员工、角色和楼宇自动限制数据范围。调用方不得传入任意 SQL 或自行
声明员工角色。

## 6. 通知网关契约

配置项：

- `NOTIFICATION_GATEWAY_URL`
- `NOTIFICATION_GATEWAY_TOKEN`
- `NOTIFICATION_REQUEST_TIMEOUT_SECONDS`
- `NOTIFICATION_MAX_RETRIES`
- `NOTIFICATION_RETRY_BASE_SECONDS`
- `NOTIFICATION_RETRY_MAX_SECONDS`

采购后端向通知网关发送 `POST` 请求。

请求头：

- `Authorization: Bearer <token>`，仅在配置令牌时发送
- `Idempotency-Key: <notification.dedup_key>`
- `X-Notification-Id: <notification_id>`

请求体：

```json
{
  "notification_id": 1001,
  "dedup_key": "PURCHASE_COMPLETED:101:90001",
  "event_type": "PURCHASE_COMPLETED",
  "platform_type": "FEISHU",
  "receiver_platform_user_id": "ou_xxx",
  "payload": {
    "request_no": "PR202607300001"
  }
}
```

网关返回任意 `2xx` 状态表示成功；其他状态或网络异常按发送失败处理。网关也必须
按 `Idempotency-Key` 保证幂等。

后台单次处理：

```powershell
& 'F:\Anaconda\envs\purchasing-agent\python.exe' -m app.workers.notifications
```

服务启动后执行真实 HTTP 冒烟检查：

```powershell

& 'F:\Anaconda\envs\purchasing-agent\python.exe' scripts\live_http_smoke.py
```

脚本会创建临时 Agent 会话并在结束后清理，不会触发真实通知发送。
