## 权限和数据边界

- 所有接口继续使用可信网关身份签名。
- 管理员可读取全部业务范围。
- 楼长只读取所属楼宇；显式请求其他楼宇时返回 403。
- 其他角色只读取本人创建、当前处理或曾经办理的申请。
- 聚合、风险和相似案例只使用当前用户可见记录，不能通过汇总绕过行级权限。
- Agent 只提交固定 Pydantic DSL，不能提交 SQL、表名、字段表达式或任意排序字段。

## 受控查询 DSL

支持的条件包括日期、楼宇、设备专业、设备名称、品牌、型号、供应商、采购状态和价格
范围。状态、设备专业、分组、聚合、排序字段和排序方向均为枚举白名单。

第一版聚合仅支持：

- `COUNT`
- `AVERAGE_UNIT_PRICE`
- `MEDIAN_UNIT_PRICE`
- `TOTAL_AMOUNT`

分组仅支持品牌、楼宇、供应商和设备名称。金额统计只基于实际采购执行记录，响应中的
`effective_query.statistics_basis` 会明确返回 `ACTUAL_EXECUTION_ONLY`。

默认查询最近 365 天，单次日期范围不超过 366 天，分页每页不超过 100 行，扫描行数
默认不超过 5000，查询默认 10 秒超时。超过边界时要求缩小查询范围，不做隐式截断。

## 风险口径

每项风险只返回事实、指标、阈值、时间范围和相关申请 ID，不返回模型生成的风险结论。

| 风险 | 第一版口径 |
|---|---|
| 重复申请 | 相同楼宇、同设备名称或同设备专业与品牌，30 天内存在其他申请 |
| 价格异常 | 当前实际/预计单价高于近 180 天同类设备实际历史中位价 20% 以上 |
| 数量异常 | 申请数量高于同类历史平均值 50% 以上，或实收数量不等于申请数量 |
| 黑名单供应商 | 当前拟选或实际供应商在评估时点处于有效黑名单 |
| 供应商延期 | 实际入库日晚于预计到货日，或预计到货日已过且有采购记录但尚未入库 |
| 长期未入库 | 已采购超过 14 天仍没有入库记录 |
| 相似历史申请 | 规则相似度不低于 0.40，返回可解释匹配因素和相关申请 ID |

缺少预计到货日的记录不计为延期，也不进入供应商延期率分母。部分入库和超量入库均
计为入库数量异常，并分别保留负数或正数的 `receipt_variance`。

## 供应商履约统计

接口同时返回延期与数量异常的分子、分母和比例。预计到货日缺失的记录不进入延期率
分母；没有入库记录的采购不进入数量异常率分母。统计时间范围默认 365 天，最大 1095
天，并且只汇总当前用户可见采购记录。

## 相似案例

第一版使用 `RULE_WEIGHTED_V1`，按设备专业、设备名称、品牌、型号、楼宇和数量区间进行
加权。每个结果返回 `similarity_score` 和 `matched_factors`，不使用业务后端向量检索。
