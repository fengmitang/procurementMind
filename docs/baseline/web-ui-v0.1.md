# Web 智能协同入口基线 v0.1

记录日期：2026-08-05

## 入口与服务边界

- 开发体验地址：`http://127.0.0.1:8000/demo/`
- 采购业务后端：`http://127.0.0.1:8000`
- 独立 Agent 服务：`http://127.0.0.1:8100`
- 浏览器智能请求只提交到固定的 `POST /demo-api/agent-chat`。
- 开发后端只向配置的 `AGENT_SERVICE_URL` 转发 `POST /api/v1/chat`，前端不能传入或改写目标地址。
- 浏览器资源不包含身份网关密钥、签名头或模型密钥。

## 已验收能力

- 对话输入、示例问题、处理中、完成、部分完成和错误状态。
- 身份随左侧 TEST 体验角色切换，会话在切换身份时重置。
- 复杂查询展示自然语言总结、实际查询口径、汇总指标、分组结果和明细表格。
- 风险调查展示风险事实、指标、规则阈值、待核实原因、人工核实项、信息缺口及证据状态。
- 知识材料尚未提供时明确返回能力未接入提示，不生成虚构制度答案。
- 既有采购流程、供应商、历史、Agent 存储和通知页签保持不变。
