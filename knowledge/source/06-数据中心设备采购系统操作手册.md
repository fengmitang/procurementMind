> 本文件为数据中心设备采购智能协同系统项目使用的内部业务指引，用于规范系统中的采购办理和功能演示，不替代企业现行正式管理制度。

## 一、手册说明

本手册用于指导用户通过网页办理采购申请、审核、采购、入库、供应商查询、历史记录查询和智能辅助。

页面名称和按钮位置可能随版本调整，实际操作以系统当期页面展示为准。

## 二、登录与工作台

### 1. 进入系统

打开系统网页后完成身份验证。登录成功后，系统根据本人角色展示可使用的功能和可查看的数据。

### 2. 核对当前身份

进入工作台后，应当核对页面显示的姓名、角色和所属楼宇。发现信息不一致时，不要继续办理，联系系统管理员核实。

### 3. 查看待办

需求人主要查看本人申请；楼长、采购员和仓库管理员主要查看“待我处理”的事项。多角色用户应当确认当前正在使用的角色。

## 三、需求人操作

### 1. 新建采购申请

1. 进入采购工作台；
2. 选择“新建采购申请”；
3. 选择采购设备所属楼宇；
4. 创建草稿；
5. 进入申请详情填写采购信息。

办理结果：系统生成采购申请编号，状态为“草稿”。

### 2. 保存采购草稿

1. 填写已经确认的采购信息；
2. 选择“保存”；
3. 查看系统提示的未完成内容；
4. 后续可再次打开草稿继续填写。

草稿阶段允许信息不完整，不需要为了保存填写无意义内容。

### 3. 补充申请资料

提交前至少确认：

- 设备专业；
- 设备名称；
- 数量；
- 计量单位；
- 申请原因。

品牌、型号和备注根据实际情况填写。

### 4. 提交楼长审核

1. 确认申请信息；
2. 查看可选楼长；
3. 选择负责本楼宇的楼长；
4. 提交审核；
5. 查看状态是否变为“待楼长审核”。

提交后，需求人不能直接修改申请。发现信息错误时，应当联系楼长处理或等待驳回后修改。

### 5. 处理驳回申请

1. 在本人申请中打开状态为“已驳回”的采购申请；
2. 阅读楼长填写的驳回原因；
3. 按要求修改申请内容；
4. 核对是否已解决全部问题；
5. 重新选择楼长；
6. 再次提交审核。

### 6. 查看办理进度

打开采购申请详情，可查看当前状态、当前处理人和流程履历。已经完成的步骤会显示经办人和办理时间。

## 四、楼长操作

### 1. 查看待审核申请

1. 切换至楼长角色；
2. 打开待办列表；
3. 选择一张待审核申请；
4. 核对楼宇、设备、数量、申请原因和历史记录。

### 2. 修改需求信息

审核期间发现设备名称、数量、品牌型号或申请说明需要修正时，楼长可以在本人当前办理的申请中修改需求信息。

修改前应当与需求人核实，不得擅自改变采购用途。

### 3. 填写审核资料

至少填写：

- 预计单价；
- 付款方式；
- 预计到货日期；
- 质保信息。

需要时补充拟选供应商、合同要求、联系信息和审核备注。

预计总价由系统根据数量和预计单价计算。

### 4. 驳回申请

1. 确认申请确需需求人修改；
2. 选择“驳回”；
3. 填写具体原因和修改要求；
4. 提交；
5. 确认状态变为“已驳回”。

### 5. 审核通过并提交采购员

1. 核对申请和审核资料；
2. 查看风险提示和历史参考；
3. 完成必要核实；
4. 选择采购员；
5. 提交采购；
6. 确认状态变为“待采购”。

### 6. 生成风险摘要

1. 打开待审核采购申请；
2. 选择“生成风险摘要”；
3. 查看系统事实、风险提示、相关历史和待核实事项；
4. 核对引用来源；
5. 根据实际情况补充调查；
6. 由本人作出审批决定。

风险摘要不等同于审批结论。

### 7. 生成审批意见草稿

1. 完成风险核实；
2. 选择需要的意见类型；
3. 查看系统生成的草稿；
4. 修改不准确或不完整内容；
5. 确认后再保存。

未经本人确认，草稿不会作为正式意见写入。

## 五、采购员操作

### 1. 查看待采购任务

1. 切换至采购员角色；
2. 打开待办列表；
3. 选择采购申请；
4. 核对需求信息和楼长审核意见。

### 2. 开始采购

选择“开始采购”，确认申请状态变为“采购中”。开始采购后，方可登记实际供应商和成交信息。

### 3. 查询或新增供应商

1. 在供应商页面按名称或统一社会信用代码检索；
2. 核对是否已有主档；
3. 没有匹配供应商时，选择新增；
4. 填写供应商基本资料并保存。

系统提示疑似重复时，应当先核实已有供应商。

### 4. 查看采购推荐

可以按设备名称查看历史品牌型号、相似采购和历史供应商。推荐结果仅供询价和比较，不得直接作为最终选择依据。

### 5. 登记采购结果

填写：

- 实际供应商；
- 实际单价；
- 采购时间；
- 需要保存的供应商资料；
- 税率和采购备注等补充内容。

实际总价由系统计算。提交前核对金额和供应商信息。

### 6. 更新供应商主档

本次采购资料已经核实且需要更新供应商主档时，可以选择同步更新。仅需保留本次采购资料而不修改主档时，不选择同步更新。

### 7. 提交仓库

1. 确认采购资料已经保存；
2. 选择仓库管理员；
3. 提交入库；
4. 确认状态变为“待入库”。

## 六、仓库管理员操作

### 1. 查看待入库任务

1. 切换至仓库管理员角色；
2. 打开待办列表；
3. 选择采购申请；
4. 核对设备名称、申请数量、供应商和采购说明。

### 2. 登记入库信息

填写：

- 仓库位置；
- 实收数量；
- 入库说明。

实收数量少于申请数量时，必须填写差异原因和后续安排。

### 3. 完成采购流程

1. 核对实物和登记信息；
2. 保存入库资料；
3. 确认完成；
4. 查看状态是否变为“已完成”。

完成后不得随意修改历史记录。

## 七、供应商与黑名单操作

### 1. 查看供应商

在供应商页面输入名称或统一社会信用代码进行查询。页面展示供应商基本资料和当前黑名单状态。

### 2. 查看敏感信息

采购员和系统管理员在业务需要范围内可以查看完整财务信息。其他角色看到的银行账号为脱敏内容。

### 3. 登记黑名单

楼长只能根据本人楼宇内已经完成的采购登记实际供应商黑名单。

操作时：

1. 选择对应供应商；
2. 选择已完成采购；
3. 填写黑名单类型和原因；
4. 选择永久或限时；
5. 限时黑名单填写开始和结束时间；
6. 核对后提交。

### 4. 提前解除黑名单

原登记楼长或系统管理员可以提前解除有效黑名单。解除时必须填写原因。

## 八、历史记录与流程履历

### 1. 查询历史采购

可以按采购编号、设备名称、品牌、型号、供应商、状态和时间范围查询。

不同角色能够查看的数据范围不同，以系统权限结果为准。

### 2. 查看流程履历

打开采购申请的流程履历，可查看创建、提交、审核、采购、入库和完成等办理记录。

### 3. 查看联系方式

流程履历中的手机号默认脱敏。确因当前采购办理需要时，可以通过系统提供的单独查看入口获取完整号码。

## 九、智能助手使用

### 1. 查询流程和规则

可以提问：

- 如何提交采购申请；
- 被驳回后如何处理；
- 楼长需要填写哪些内容；
- 黑名单如何生效；
- 入库数量不足如何填写。

回答应当显示所依据的文件和章节。

### 2. 查询当前业务

可以提问：

- 这张采购申请现在由谁处理；
- 为什么当前不能提交；
- 当前供应商是否在黑名单中；
- 这张申请是否存在相似历史采购。

涉及实时状态时，以系统查询结果为准。

### 3. 进行复杂查询

可以使用自然语言组合条件，例如：

“查询过去半年一号楼采购的服务器硬盘，排除当前受限供应商，并按品牌比较平均价格。”

系统会展示识别出的查询条件、结果表格和统计口径。用户应当检查条件是否与原意一致。

### 4. 连续追问

在同一查询中可以继续补充条件，例如“再排除有延期记录的供应商”。开始新的问题时，应当明确说明，避免旧条件被继续使用。

### 5. 查看引用和来源

制度类回答应当显示文件名称和相关章节；数据类回答应当说明查询时间范围和数据范围。没有可靠来源的内容，不应作为业务依据。

### 6. 信息不足

智能助手提示“信息不足”时，说明现有文档或业务数据无法支持明确结论。用户应当补充材料或转人工核实。

## 十、常见异常处理

### 1. 提示无权查看

确认本人角色、所属楼宇和当前处理人。仍有疑问时联系系统管理员。

### 2. 提示信息不完整

按照页面提示补充内容。不要使用无意义文字规避校验。

### 3. 提示内容已变化

重新打开采购申请，读取最新信息后再次办理。

### 4. 提示操作已经执行

先查看当前状态和流程履历，确认前一次操作是否已经成功，不要连续重复提交。

### 5. 推荐或智能查询暂不可用

普通采购流程仍可办理时，可以继续办理；无法核实关键事实时，应当暂停审批或提交。

## 十一、使用注意事项

1. 不得将账号交由他人使用；
2. 不得截图、复制或传播无关敏感信息；
3. 不得通过修改页面内容绕过业务流程；
4. 不得将智能助手输出直接作为正式审批结论；
5. 发现数据错误、权限异常或流程异常时，应当及时反馈。
