## 已冻结业务规则

- 一张采购申请只包含一种设备。
- 采购状态统一为 `DRAFT`、`PENDING_REVIEW`、`REJECTED`、`PENDING_PURCHASE`、`PURCHASING`、`PENDING_WAREHOUSE`、`COMPLETED`。
- 预计价格和实际价格均保存单价与总价，总价由后端计算并校验。
- 每个楼长审核轮次对应一条 `purchase_review`，从 `DRAFT` 更新为 `COMPLETED`。
- 入库数量必须大于 0，可以少于、等于或多于申请数量；少于申请数量时备注必填。
- 本次采购始终保存供应商资料快照；只有采购员明确确认时才更新供应商主档。
- 有效黑名单可由原登记楼长或系统管理员提前解除。
- 关键操作使用 `expected_version` 防止并发覆盖，使用 `action_token` 防止重复执行。
- 平台消息使用 `external_message_id` 去重。
- 正式业务事实保存在 MySQL，Redis 只保存 Agent 实时短期状态。
- 通知通过 Outbox 异步发送，发送失败不回滚采购事务。

## 已完成任务：1. 技术基线

技术选型文档已经确定：

- Python 3.11+；本项目实际使用 Python 3.12.13。
- FastAPI 模块化单体，不使用 Spring Boot 或微服务。
- Router、Schema、Service、Domain、Repository、Integration 分层。
- SQLAlchemy 2.x 和 Alembic。
- MySQL 8.x 保存业务事实、历史记录、完整消息和关键会话快照。
- Redis 及 redis-py asyncio 保存实时会话、缓存、短期去重和临时锁。
- Pydantic 负责请求、响应、配置和结构化输出。
- httpx 负责异步外部 HTTP 调用。
- pytest 负责单元、接口和集成测试。
- Docker Compose 负责可复现的服务编排。
- OpenAPI 作为 Agent 和其他调用方的接口契约。
- Agent 不直接修改 ORM 模型，只能调用业务 Service 或 HTTP API。

项目补充采用：

- `pyproject.toml` 统一维护项目元数据、依赖和工具配置。
- pydantic-settings 管理环境配置。
- pytest-asyncio 支持异步测试。
- Ruff 负责代码检查和格式化。

开发环境约定：

- 开发阶段使用 Docker Compose 运行 MySQL 8.x。
- MySQL 数据使用独立 Docker Volume 持久化，不与本机现有 MySQL 数据目录混用。
- Redis 同样通过 Docker Compose 启动。
- FastAPI 开发服务先在本机 Conda 环境运行；部署阶段再将 FastAPI 一并容器化。
- 项目根目录 `.env` 使用 Docker MySQL 和 Redis 的开发连接配置，真实密钥不提交 Git。

Docker 隔离硬性要求：

- Compose 项目名固定为 `procurement-agent`。
- MySQL 容器名固定为 `procurement-agent-mysql`，主机端口使用 `3307`。
- Redis 容器名固定为 `procurement-agent-redis`，主机端口使用 `6380`。
- 独立网络固定为 `procurement-agent-network`，不得加入其他项目网络。
- 独立数据卷固定为 `procurement-agent-mysql-data` 和 `procurement-agent-redis-data`。
- MySQL 独立数据库固定为 `procurement_agent`。
- MySQL 使用独立应用账号 `procurement_agent_app`，应用不使用 root 账号。
- Redis 使用独立容器实例和独立数据卷，不连接或复用其他项目 Redis。
- Compose 不声明 external network 或 external volume，不复用现有 Docker 资源。
- 不挂载本机已有 MySQL 数据目录，不修改本机 MySQL 配置和数据。
- 未经明确确认不得执行 `docker compose down -v` 或删除项目数据卷。

验收条件：

- `[x]` 技术组合得到确认。
- `[x]` 明确使用 SQLAlchemy AsyncSession 和 asyncmy。
- `[x]` 明确开发环境中 MySQL 和 Redis 通过 Docker Compose 运行。
- `[x]` 明确首期提供 HTTP REST API。
